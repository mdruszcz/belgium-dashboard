# 🇧🇪 Belgique — Dashboard Économique LIVE (2026)

Dashboard économique interactif et **temps réel simulé** présentant les principaux indicateurs macroéconomiques de la Belgique pour l’année 2026.

Le projet vise à rendre **visuels, concrets et compréhensibles** des agrégats souvent abstraits : dette, déficit, population, dépenses publiques, emploi, recettes fiscales.

👉 **Aucun backend. 100 % HTML/CSS/JS. Déploiement instantané.**

---

## 🔴 Fonctionnalités principales

- 📈 **Compteurs dynamiques en temps réel**
  - Population
  - Dette publique
  - Dépenses et recettes
  - Déficit cumulé
- 🕒 Calculs continus **par seconde**
- 🎨 Interface inspirée des couleurs nationales belges
- 📊 Indicateurs clés :
  - PIB nominal
  - Dette / PIB
  - Dette par habitant
  - Taux d’emploi et de chômage (national & régional)
- 📱 **Responsive** (desktop / tablette / mobile)

---

## 📊 Sources & hypothèses

Les données sont des **projections 2026**, basées sur :
- Commission européenne
- Banque nationale de Belgique (BNB)
- FMI
- Statbel
- Bureau fédéral du Plan

⚠️ **Important**  
Les valeurs évoluent de manière *linéaire et simulée* à partir d’ordres de grandeur macroéconomiques annuels.  
Ce dashboard **n’est pas un outil statistique officiel**, mais un outil de visualisation pédagogique et analytique.
